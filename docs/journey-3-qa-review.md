# Journey-3 文档题评分

文档题使用固定的知识库资料。每道题的生效评分项和证据摘录都在对应的 [case 配置](../cases/journey-3)中。QA 和生产的 Journey-3 工作区可在 `journey3_benchmark.case_goldens` 查阅 117 道题的当前参考事实、评分项及证据。

评分按题目要求核对可独立判断的事实。数字核对单位和范围，同义表达可以命中同一事实。资料不足的题评估回答是否如实说明可确认的范围。引用质量、工具调用和耗时分别记录。

复核使用固定知识库的完整索引正文。对于价格表、连接器目录和事件台账，参考数值用原表复算。文档存在版本或字段差异时，评分项明确适用条件。多轮追问按实际会话上下文分别评分。
