## 实际执行与回执

以下读取命令均返回exit_code=0：

```text
rtk read AGENTS.md
rtk read TASK.md
rtk read <local-RTK-instructions>
rtk read samples/T043/task.md
rtk read samples/shared/product.md
rtk read <local-path>
```

随后运行 `rtk proxy python3 - <<'PY'` Python脚本，实际创建 `results/T043` 并通过 `Path.write_text` 写入 `result.md` 与本执行记录。脚本输出写入文件大小和排期行数；这仅为交付文件存在性核对，不是业务效果验证或评分。完整业务产物为四周12条选题表，逐条给出受众、渠道、观点、素材及行动引导。

## 数据与计算口径

- 120−60=60分钟；(120−60)/120=50%。表述限于输入中的20单试点平均耗时变化，未外推至所有客户。
- 第1周合成算例：10,000+800=10,800元，10,300+200=10,500元。假设数量、币种、含税口径一致，仅用于说明运费影响；不是产品实际运行结果。
- 排期为相对周，每周3条，共4周12条。未擅自设定起始日期、真实账号、价格、搜索量或绩效承诺。
