## 实际命令与回执

工作目录：本 case 根目录（读取 RTK 指令使用绝对路径）。

1. `rtk read <local-RTK-instructions>`：退出码 0，返回 RTK 使用规则。
2. `rtk read AGENTS.md TASK.md`：退出码 0，返回范围、输入及交付要求。
3. `rtk read samples/T039/task.md samples/shared/incident.md`：退出码 0，读取完整任务与事故记录。
4. `rtk proxy python3 - <<'PY' ... PY`：实际创建 `results/T039`，使用 Python `Path.write_text` 写入本文件与 `result.md`；正文包含时间线、影响、处置、根因状态及待核实事项。
