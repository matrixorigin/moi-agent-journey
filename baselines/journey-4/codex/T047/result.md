# 品牌语言指南

适用于产品界面、帮助文档、技术说明和营销材料。依据：`samples/shared/brand.md`。以下示例是编辑建议，不代表新增的产品能力或商业政策。

## 语气

- **准确**：只描述有依据的能力，说明处理方式与边界；不把校验或字段映射写成结果绝对正确。
- **直接**：先说客户能做什么，再解释必要机制。短句表达，一个句子说明一件事，减少术语堆叠。
- **尊重客户**：帮助客户核对和判断，不贬低其工作，不宣称替代整个团队；遇到信息不全，明确标为“待确认”。

## 统一用词

| 场景 | 统一表达 | 使用规则 |
|---|---|---|
| 比较不同供应商报价 | 报价比较 | 同一功能统一命名，避免在“比价”“报价对比”间切换。 |
| 表示包含税费的总金额 | 含税总价 | 仅在税费口径明确且包含税费时使用；税费信息不全时标为“待确认”，不把未税金额称为含税总价。 |
| 信息缺失或尚未核实 | 待确认 | 尽可能同时说明具体缺项，不将其写成已确认事实。 |
| 面向客户描述 schema | 统一字段格式 | 技术文档可保留 schema，但首次出现应解释为“统一字段格式（schema）”。 |
| 描述校验能力 | 通过结构化校验识别缺失项 | 避免扩写为“发现所有错误”或“保证结果正确”。 |
| 描述信息可追溯性 | 保留来源 | 不扩写为未获资料支持的审计认证或合规承诺。 |

## 禁用承诺与表达边界

| 禁用表达 | 原因与替代方向 |
|---|---|
| “零错误”“保证100%准确”及同义表达 | 资料不支持绝对准确性承诺。改为具体说明字段映射、缺失项校验及来源保留。 |
| “全自动替代员工”“替代整个采购团队” | 超出能力依据，也忽略客户的判断与职责。改为说明支持报价比较的具体步骤。 |
| “行业第一”及无依据的领先排名 | 缺乏比较范围与证据。改为描述实际能力。 |
| “三分钟完成”“三分钟替代……”等确定时效 | 资料未提供处理时长依据，删除时效承诺。 |
| “永久免费无限量” | 仅出现在待修改营销草稿中，不能作为已确认政策。未获得已核实的价格与额度依据前，删除该承诺。 |

不能通过添加“几乎”“基本”“通常”等词保留同类无依据承诺。也不应改写成未经资料支持的节省比例、交付时长或收益数字。

## 前后修改示例

| 修改前 | 修改后 | 修改理由 |
|---|---|---|
| 保证100%准确。 | 系统通过结构化校验识别报价中的缺失项，并保留来源供核对。 | 用已知机制替代绝对准确性承诺。 |
| 三分钟替代整个采购团队。 | 系统将不同格式的报价字段整理为统一格式，支持报价比较。 | 删除未经证实的时效和团队替代承诺。 |
| 永久免费无限量。 | 使用系统统一整理报价字段，并识别缺失项。 | 删除未经确认的价格与额度承诺，回到已有能力。 |
| 行业第一的智能比价工具。 | 支持报价比较，识别报价中的缺失项并保留来源。 | 删除排名，统一使用“报价比较”。 |
| 系统将异构报价字段映射到统一schema，通过结构化校验识别缺失项并保留来源。 | 系统将不同格式的报价字段整理为统一字段格式，并通过结构化校验识别缺失项，同时保留来源。 | 保留原意，用更易懂的语言解释技术机制。 |
| 报价对比：税后合计。 | 报价比较：含税总价。 | 统一功能与金额术语；此示例仅适用于已确认包含税费的金额。 |
| 信息不全，无法处理。 | 报价信息存在缺失项，相关内容待确认。 | 明确状态，避免生硬归责或无依据地宣称完全无法处理。 |
| 全自动处理，无需人工核对。 | 系统识别报价缺失项，并保留来源，便于客户核对。 | 去掉无人参与的承诺，保留客户判断空间。 |

## 可用的营销草稿替换稿

将不同格式的报价字段整理为统一格式，支持报价比较。系统通过结构化校验识别缺失项，并保留来源，便于核对。

## 发布前核对

确认能力描述能在资料中找到依据；统一使用“报价比较”“含税总价”“待确认”；删除准确率、替代人员、排名、时效、价格和额度方面未经证实的承诺。示例中涉及的金额状态必须与实际数据一致。
