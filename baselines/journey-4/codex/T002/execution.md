## 真实命令与回执

1. `rtk proxy cat <local-RTK-instructions> <case-root>/T002/AGENTS.md <case-root>/T002/TASK.md`
   - exit_code=0；读取命令前缀规则、case 隔离要求和任务路径。
2. `rtk proxy cat samples/T002/task.md samples/shared/idea.md`
   - 工作目录为本 case；exit_code=0；读取任务与采购比价想法全文。
3. `rtk proxy python3 - <<'PY' ... PY`
   - 工作目录为本 case；实际创建 results/T002/result.md 和本执行记录，使用 pathlib.write_text，UTF-8。
   - Python 输出文件字节数，作为写入回执（见工具执行输出）。

## 数据口径核对

- 输入没有提供真实报价、税率、币种、贸易术语或人员配置。
- 将已明确需求与建议规则、待确认项分开，人民币门槛、经理兼任一级审批、目的地全成本口径均标记为建议/待确认。
- 验收示例：40,000 × 1.13 + 800 = 46,000；48,300 - 46,000 = 2,300；2,300 / 46,000 = 5%。这些为人工核对的示例算术，不是实际报价处理结果。
- 超过 5 万元保留严格大于边界；预算未知不推导预算额度。
