# T084 边界测试结果

已复制原始 app.py，保留原有测试，新增 tests/test_boundaries.py（19 项）。未修改计算实现，以暴露现有问题。

实际执行共 20 项：9 项成功、11 项失败，进程退出码 1；完整输出见 test-run.log，校验回执见 verification.json。

|覆盖|输入或断言|实际结果|
|---|---|---|
|原有正常计算|2 × 100，无折扣 = 200|成功|
|正常折扣|2 × 100，10% 应为 180；3 × 12.5，20% 应为 30|失败，实际 200、37.5|
|合法特殊值|单件、零单价、0% 和 100%|成功|
|折扣区间内边界|100 元，0.01% 应为 99.99；99.99% 应为 0.01|失败，实际均为 100|
|负数|qty=-1；price=-0.01|成功拒绝，ValueError|
|非法折扣范围|discount=-0.01、100.01|失败，未抛出异常|
|非法折扣类型|字符串 "10"、None|成功拒绝，TypeError|
|非法折扣类型和非有限值|True、NaN、Infinity|失败，未抛出异常|
|非法数量|qty=0、1.5|失败，未抛出异常|

发现：计算使用 discount // 100 整除，导致 0～100 之间的折扣失效；缺少折扣范围和数值类型验证；数量未限制为正整数。修复建议为使用普通除法，并在计算前验证数量、价格、折扣类型与范围。本次只补测试，不修复源码。

口径：按百分比折扣计算 qty × unit_price × (1 - discount / 100)，小数断言采用 assertAlmostEqual；API 将该字段描述为 0 到 100，但没有写明折扣计算公式，该公式属于本次测试明确采用的业务解释。非法输入在函数层预期 ValueError 或 TypeError，具体异常类型并非 API 原文规定。NaN/Infinity 是函数层健壮性测试，非标准 JSON 请求值。

限制：样例只有 Python 计算函数，无 HTTP 路由、服务器入口或认证/限流实现。因此本次执行为函数层契约测试，未验证 POST、200/400/401/429 状态码、CNY 响应结构、Bearer 认证与限流，不声称完成真实 HTTP 集成测试；未访问外部接口或使用真实 token。
