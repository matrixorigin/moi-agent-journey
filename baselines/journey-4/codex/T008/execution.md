## 实际命令与回执

工作目录始终是当前 T008 根目录。所有 shell 命令以 rtk 开头。

1. `rtk proxy cat AGENTS.md TASK.md`：退出码 0，读取本 case 边界与任务要求。
2. `rtk proxy cat <local-RTK-instructions> samples/T008/task.md samples/shared/feature.md`：退出码 0，读取 RTK 规范及两个任务输入文件。
3. `rtk proxy python3 - <<'PY' ... PY`：执行 Python pathlib 脚本创建 `results/T008`，以 UTF-8 实际写入 `result.md`，并按二级标题中“｜”统计故事数量。退出码 0，真实输出为：

```text
已写入 results/T008/result.md
故事数量: 20
UTF-8 字节数: 13021
```

4. `rtk proxy python3 - <<'PY' ... PY`：执行 pathlib 脚本实际写入本 `execution.md`，然后读取两份交付文件的文件大小并输出回执。完整正文写入是步骤 3、4 中 heredoc 的内容；此处省略长篇正文，未把命令示例作为已执行业务验收。
