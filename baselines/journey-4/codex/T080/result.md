# 报价漏项审计

销售报价：200,000 元。

| 项目 | 已列成本（元） |
|---|---:|
| 硬件 | 80,000 |
| 实施 | 40,000 |
| 培训 | 10,000 |
| 云资源（2,000 元/月 × 12 个月） | 24,000 |
| 已知成本合计 | 154,000 |

已知毛利 = 200,000 − 154,000 = **46,000 元**。已知毛利率 = 46,000 ÷ 200,000 = **23%**。以上仅按已列成本计算，未列费用没有按 0 计入，不能据此认定完整项目毛利或净利润。报价和成本是否含税、税务处理口径尚未明确，以上为原始金额直接相减的暂算口径。

| 漏项/缺失信息 | 状态与需确认内容 |
|---|---|
| 运费 | 待确认：运输范围、金额与承担方 |
| 差旅 | 待确认：实施及培训是否需出差、次数、人数与费用 |
| 税费 | 待确认：报价与成本含税口径、适用税费及可抵扣情况，避免重复计入 |
| 后续维护人力 | 待确认：服务期限、工作量及人员成本；云资源目前仅列 12 个月 |
| 报价有效期 | 未写，待明确截止日期及到期后调价/重新报价规则 |

应补齐上述费用及适用口径，再复核项目收益。46,000 元是目前已知成本下的暂算余额，不能将未列费用默认包含在其中或视为无需发生。
