# 采购报价审批与导出 SOP

适用对象：首次参与采购报价整理的经办人。依据：`samples/shared/sop.md`。原文明确的标准顺序优先于口头叙述：**核对规格 → 收三家报价 → 核对含税运费 → 经理批准 → 导出 → 归档**。

## 1. 边界与执行原则

- 本流程结束于获批报价材料导出与归档，不包含向供应商下单。不得把收报价、经理批准或导出当作下单授权。
- 规格未确认，不进入正式询价；不足三家或税费、运费未明确，不提交为完整审批材料；经理未批准，不得导出。
- 批准须对应当前版本的规格、报价和费用。任何关键内容变化后，重新核对并重新取得经理批准。【假设 A4】

## 2. 角色、输入与输出

| 角色 | 责任 | 说明 |
|---|---|---|
| 经办人 | 核对规格、收集报价、整理比价、提交审批、获批后导出归档 | 【假设 A1】由同一经办人负责，实际负责人待确认 |
| 采购规格确认人 | 确认采购规格及疑问 | 【假设 A1】口述中的“问问采购规格”未明确具体岗位，须指定确认人 |
| 经理 | 对完整报价材料作出批准、退回或拒绝决定 | 原文明确必须经理批准，具体经理及代理授权待确认 |

启动输入：采购需求、待核对的规格、规格确认人、经办人及审批经理信息。规格字段、数量、单位等具体模板原文未提供，按实际采购需求补齐并书面确认。【假设 A2】

最终输出：规格确认记录、三家报价原件、含税及运费核对表、经理对相应版本的批准凭证、导出文件及归档索引。书面凭证及版本编号为可追溯性补充要求。【假设 A3】

## 3. 操作步骤

| 步骤 | 新人操作 | 完成后留下的输出 | 放行条件 |
|---|---|---|---|
| 1 核对规格 | 向指定确认人逐项核对采购规格，记录未决问题并取得确认；若已提前收到报价，先留作参考，规格确认后检查是否适用 | 已确认的规格及确认记录 | 规格明确且已确认 |
| 2 收三家报价 | 以同一已确认规格向三家供应商收集报价，保存原始报价及供应商信息；不同规格的报价先要求补齐或重新报价 | 三家可比较报价及原件 | 三家报价均与确认规格匹配 |
| 3 核对含税运费 | 逐家核对报价金额是否含税、运费是否包含；不含的要求明确税费、运费或最终含税含运总价。记录费用依据，避免重复计入 | 三家费用核对表，列明报价、税费口径、运费口径及含税含运总价 | 税费与运费均明确，能够按同一口径比较；不得把未知运费填作 0 |
| 4 经理批准 | 将规格确认记录、三家报价及费用核对表提交指定经理，注明材料版本；保存经理明确批准的凭证 | 绑定该版本的审批结果 | 仅明确批准可进入下一步；沉默、已阅或待审批不视为批准【假设 A3】 |
| 5 导出 | 检查批准版本与当前材料一致，再按指定模板导出；核对供应商、规格、金额、税费及运费与获批材料一致 | 经核对的导出文件及核对记录 | 有经理批准且导出内容与获批版本一致 |
| 6 归档 | 将上述材料及审批凭证一起归档，记录文件位置、版本、经办人和日期，检查可打开并可检索 | 完整档案包及索引 | 六步证据齐全，归档可访问；缺项标记“待补齐” |

费用计算口径【假设 A2】：每家含税含运总价 = 已确认报价基数 + 未包含的税费 + 未包含的运费；已经包含的项目不得重复相加。税额依据供应商确认口径，不自行猜税率；币种、数量或计价单位不一致时先统一确认口径。原文没有金额数据，本次不做数值计算。

## 4. 批准与异常分支

| 情况 | 经办人处理 | 恢复条件 |
|---|---|---|
| 规格缺失、冲突或无人确认 | 暂停正式询价，列出问题，交采购规格确认人澄清 | 已取得一致的规格确认 |
| 不足三家、报价无法比较 | 继续补齐或要求重新报价，标记材料不完整；原文未提供豁免规则，不自行减少家数 | 三家可比报价齐全；如需例外，另行确认正式制度 |
| 税费或运费不清、报价中费用矛盾 | 向供应商澄清并保留答复，更新核对表；不以“价格已核对”代替运费核对 | 含税含运口径明确 |
| 经理未回复、退回或拒绝 | 不导出；未回复则等待或按内部渠道跟进，退回则补正后重提，拒绝则记录结果并停止 | 经理明确批准当前版本 |
| 经理不在或找不到审批人 | 保持待审批，确认组织指定的有权审批人；经办人不得自行代批 | 有权经理明确批准 |
| 批准后规格、报价或费用变化 | 标记旧批准不再覆盖变更内容，回到受影响步骤，完成复核后重新提交经理【假设 A4】 | 更新版本重新获批 |
| 未批准已导出 | 停止继续使用或流转该导出件，标记“未经批准”，保留事实记录并报告经理；补齐前置步骤重新审批，不倒签或追溯认定原导出合规【假设 A5】 | 新版本获批后重新导出；原异常留痕 |
| 有人直接向供应商下单 | 立即制止继续下单，核实是否已发送、确认或产生承诺，记录并报告经理；由有权负责人决定暂停、撤销或后续处理，不擅自再下单或承诺取消【假设 A5】 | 异常按负责人决定处置；报价流程按标准补正，下单仍须另行授权 |
| 导出失败、内容错误或归档失败 | 保留获批源材料；修复导出并复核，或补齐归档；若发现源材料也有变化，重新走审批 | 导出一致、材料完整且可访问 |

- **A3 凭证与交付约定**：原文未规定审批载体、文件格式、导出系统、模板、归档路径、访问权限和保留期限。建议采用可追溯批准记录并绑定版本；启用前由流程负责人确认这些约定。没有正式模板时，不自行声称符合公司制度。
- **A4 变更重批**：原文未描述批准后变更。本文采用变更后重新核对、重新批准的保守执行规则，待流程负责人确认。
