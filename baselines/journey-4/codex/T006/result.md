# 采购报价比较：完整用户旅程

## 目标与设计口径

采购将 CSV/Excel 报价整理成可比较的对照表，检查缺失项与比较口径，交由经理确认，再导出已确认版本。用户始终能知道当前处理阶段、仍需处理的问题和下一步。

**已知范围**：识别供应商、规格、数量、税费、运费、交期；提供对照表；经理确认后导出；缺失项必须提示。采购可编辑，财务可看价格，访客仅看公开摘要。

**以下为设计建议，需产品确认**：草稿与版本保存；处理进度；字段映射和纠错；确认后修改使原确认失效。输入未明确币种、税价口径、经理授权方式、公开摘要内容、文件限制和保留期限，不将它们当作已有能力。经理采用明确的审批授权，不默认所有财务或采购都有确认权。

## 角色与入口

| 角色 | 入口与可做事项 | 边界与提示 |
| --- | --- | --- |
| 采购 | 报价比较列表 → 新建/继续草稿；上传、校正、提交确认 | 不能自行绕过经理确认导出 |
| 财务 | 获授权报价的价格查看页 | 默认只读；价格的可见范围需确认；不默认可看源文件、编辑或审批 |
| 经理 | 待确认列表 → 指定版本的比较表与问题摘要 | 仅获确认授权者可确认或退回；导出另做权限检查 |
| 访客 | 已发布的公开摘要链接 | 不展示价格、原始报价、源文件或私有字段；没有公开摘要时显示不可用，不降级开放内部表格 |

所有入口、下载地址与接口遵守相同权限；采购草稿不会自动公开。

## 一、首次使用：从空白到可比较

| 阶段 | 用户目标与操作 | 系统反馈与下一步 |
| --- | --- | --- |
| 1. 空状态 | 采购进入报价比较，了解需要什么材料 | 展示“上传 CSV 或 Excel → 检查识别结果 → 提交经理确认 → 导出”；列明七类识别字段，并提示缺失项会标记。提供“新建比较” |
| 2. 选择文件 | 选择本次需要比较的报价文件 | 展示文件名、上传状态和可移除操作；文件格式、大小、工作表等限制以实际支持能力明确展示，不编造具体阈值 |
| 3. 上传与识别 | 等待系统读取 | 区分上传、读取、识别阶段；提供取消。多文件逐一显示状态，避免一份失败掩盖其他结果；处理未结束时不呈现“识别完成” |
| 4. 检查映射 | 核对供应商、规格、数量、税费、运费、交期 | 预览源数据与识别字段的对应关系，标出缺失、歧义和无法读取的单元格；无法判断的字段保留“待确认”，不自动补零 |
| 5. 建立对照表 | 采购校正识别结果并保存 | 同一可比项目并列展示供应商报价；规格/数量不一致时明显提示，避免把不同项目当作同价比较；标注源文件、行/工作表以便追溯 |

**首次使用完成点**：采购能看到完整对照表、定位每个问题，并明确哪些项目可比较，哪些仍需处理；上传成功本身不代表任务成功。

## 二、成功路径：检查、确认与导出

1. **采购复核**：对照表集中列出缺失项，支持定位到对应供应商、项目和字段。税费/运费未知与确实为零分开显示，交期未提供不推测。展示已提供的价格口径；币种、含税/未税、单位等影响比较时提示采购核实，未统一前不生成确定的总价排名。
2. **提交确认**：展示本次提交的版本、供应商、比较项目和未解决项清单。建议必需识别字段缺失时阻止提交，并说明补充方式；业务允许例外的规则尚待确认，不能静默放行。提交后显示“待经理确认”，并保留可回查的提交内容。
3. **经理审阅**：经理查看指定版本的差异、缺失及异常提示。选择“确认”或“退回修改”；退回时填写原因，采购在原草稿上继续处理。确认前提示“确认后可导出本版本”。不把系统识别或价格较低等同于经理决策。
4. **确认完成**：显示确认人、时间和版本；状态变为“已确认，可导出”。若采购继续修改，生成待复核版本，原确认只适用于原版本，新版本须重新确认。
5. **导出**：有导出权限的用户导出已确认版本。下载前显示版本与内容范围，文件内保留版本和确认信息。格式和字段范围待确定，不承诺具体导出格式。导出失败不撤销经理确认，可针对同一版本重试。
6. **完成与复用**：显示“文件已生成，可下载”，并保留再次下载入口；用户回到列表后能识别已确认版本与后续草稿。不能仅凭发起下载就断言文件已被用户本地保存。

**成功终点**：用户取得与经理确认版本一致、权限匹配的比较结果；该流程不自动下单或向供应商发送消息。

## 三、失败与恢复路径

| 触发点 | 用户看到什么 | 恢复操作与数据处理 |
| --- | --- | --- |
| 格式不支持、文件损坏/加密、空表 | 明确是哪份文件、哪一步失败；不只显示“出错了” | 重新选择或提供可读取版本；保留其他文件及已完成工作，失败文件不能冒充已识别 |
| 网络中断/识别超时 | 区分上传未完成与结果暂不可用 | 查询原处理状态再重试，避免重复创建；恢复能力不足时明确需要重新上传 |
| 列名不清、字段缺失 | 表内标记及问题列表，例如“供应商 A 的运费未提供” | 采购校正映射、手动补充或替换文件；实时更新问题数，财务与访客不能代改 |
| 规格、数量或价格口径不一致 | 提示“暂不可直接比较”及具体差异 | 采购核对并统一口径，或拆分比较项目；保留原值与修改记录，不把缺失价格当零 |
| 经理退回 | 状态“已退回”与退回原因 | 采购定位问题、修改并重新提交；已退回版本不能按已确认版本导出 |
| 确认时版本已变更 | 提示“内容已更新，请重新审阅” | 加载最新待确认版本，禁止将旧审阅结果应用到新内容 |
| 无权限或会话失效 | 提示需要登录/申请权限，不展示私有内容 | 登录后重新鉴权并返回允许访问的页面；权限恢复不等于自动批准原操作 |
| 导出生成失败/下载中断 | 显示确认仍有效、失败步骤和重试入口 | 重试同一已确认版本；若已生成则重新下载，避免误导用户重新提交审批 |

每次恢复后都回到原任务的可识别状态，保留已保存内容；不能恢复的部分明确列出，不以“请重试”替代原因与下一步。

## 四、退出与返回

| 退出时点 | 交互与返回规则 |
| --- | --- |
| 尚未上传 | 直接退出，不产生空任务 |
| 上传/识别中 | 区分“离开页面”与“取消处理”；支持后台继续才承诺继续。取消时说明已上传文件如何处置；重新进入展示真实处理状态 |
| 存在未保存修改 | 提供“保存草稿并退出 / 放弃本次修改 / 继续编辑”；保存成功才离开，保存失败留在当前页并保留输入 |
| 草稿已保存 | 直接返回列表；再次进入恢复草稿及问题清单，不要求重做已完成的字段核对 |
| 待确认 | 离开不撤回提交；如提供撤回，须独立明确操作并使经理旧页面无法继续确认 |
| 已确认或导出后 | 可返回列表、稍后再下载；修改另起待确认版本。退出不删除原记录 |
| 退出账号/访问被撤销 | 立即停止受限操作并隐藏私有内容；重新登录后重新鉴权 |

“退出页面”“撤回提交”“删除任务”是不同操作。删除与文件保留、草稿自动保存、取消后的清理机制不在已知需求中，需另行确定；界面不得用退出按钮暗含删除。

## 验收走查与待确认决策

- 首次用户上传包含七类字段的可读取报价，能核对映射并进入对照表；缺失税费/运费时看到具体位置，不被默认为零。
- 采购完成检查后提交；经理确认版本 V1，导出内容对应 V1；V2 修改后不能沿用 V1 的确认。
- 单文件失败、经理退回、导出失败均有明确恢复入口；恢复不抹除其他已保存内容，不错误改变确认状态。
- 草稿退出再进入能恢复；未保存修改退出有清晰选择，保存失败不丢输入。
- 分别以采购、财务、经理与访客身份走查页面及直接文件地址：编辑、价格可见、确认、导出和公开摘要符合各自权限。

上线前需明确：经理授权与导出角色；缺失项是否允许带说明例外提交；价格比较口径；文件及多工作表支持范围；公开摘要发布者、白名单与撤销方式；草稿/源文件保留和清理规则。以上为待决策事项，不影响本稿对完整旅程的描述，也不表示已有实现。
