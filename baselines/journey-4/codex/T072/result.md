# 费用汇总

来源：`samples/shared/expenses.csv`，5 笔费用，总金额 **54,000.00**。源文件未说明币种、期间及含税口径，以下沿用原始金额单位，全部记录纳入汇总。

| 汇总维度 | 类别 | 笔数 | 金额 |
| --- | --- | ---: | ---: |
| 部门 | 研发 | 3 | 3,000.00 |
| 部门 | 市场 | 2 | 51,000.00 |
| 项目 | A | 2 | 2,200.00 |
| 项目 | B | 2 | 51,000.00 |
| 项目 | C | 1 | 800.00 |
| 类型 | 云资源 | 2 | 2,200.00 |
| 类型 | 活动 | 2 | 51,000.00 |
| 类型 | 差旅 | 1 | 800.00 |

按部门、项目、类型联合分组，分别为：研发 / A / 云资源 2,200.00（E1、E2），市场 / B / 活动 51,000.00（E3、E4），研发 / C / 差旅 800.00（E5）。各汇总维度均独立覆盖全部 5 笔，合计均为 54,000.00；不同维度的合计不能再次相加。

异常大额为 **E4：市场 / B / 活动，50,000.00**，占全部费用 **92.5926%**。

筛选规则为全部记录金额严格大于 `Q3 + 1.5 × IQR`。金额排序为 800、1,000、1,000、1,200、50,000，使用包含端点的线性插值分位数（位置 `(n−1)×p`），Q1=1,000，Q3=1,200，IQR=200，上界=1,500。仅 E4 超过上界。E4 为整体中位数 1,000 的 50 倍，也为同部门、项目、类型的另一笔 E3（1,000）的 50 倍。

样本仅 5 笔且费用类型不同，统计异常只能作为复核线索。需核查 E4 的活动规模、合同/发票、预算及审批，才能判断业务合理性；不据此认定录入错误或违规。异常记录仍包含在所有汇总中。

CSV 均为 UTF-8 BOM，金额保留两位小数，占比为百分数值保留四位小数：

- `by_department.csv`：部门汇总。
- `by_project.csv`：项目汇总。
- `by_type.csv`：类型汇总。
- `by_department_project_type.csv`：三个维度联合汇总。
- `large_expense_anomalies.csv`：异常明细、原始 ID、阈值与对比证据。

`verification.json` 保存输入指纹及核对结果，`execution.md` 记录执行情况。无未生成的任务产物。
