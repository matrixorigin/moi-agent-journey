# T038 SOP 偏差审计

审计依据：`samples/shared/sop.md`。标准流程为：**核对规格 → 收三家报价 → 核对含税运费 → 经理批准 → 导出 → 归档**。以下结论仅基于给定执行记录；未记录不等于已证明实际未做，但不能据此认定合规。

## R1：收报价 → 导出 → 归档

| 标准步骤 | 审计发现 | 影响 |
|---|---|---|
| 核对规格 | 记录缺失；报价前未体现规格核对 | 报价可能不对应需求，供应商方案缺乏可比性，可能选错规格 |
| 收三家报价 | 仅写“收报价”，数量不明，不能确认三家要求已满足 | 比价充分性无法验证，可能遗漏更优报价 |
| 核对含税运费 | 记录缺失 | 可能以不完整价格比较，低估总成本或出现额外费用 |
| 经理批准 | 导出前没有批准记录，为关键控制缺口 | 导出缺乏授权证据，未经批准的报价或采购方案可能进入后续环节 |
| 导出 | 有记录，但前置控制未体现 | 导出动作本身完成，不能据此认定流程合规 |
| 归档 | 有记录，归档内容完整性未说明 | 已归档不弥补前序缺口；审批、比价等证据可能仍不完整 |

**处理建议：**核查是否存在同期规格、三家报价、含税运费核对及经理批准证据。缺失的控制需补做；若报价受规格或成本修正影响，重新比价并取得经理批准，再更新导出文件和归档版本。不得以事后批准倒写成导出前已批准。

## R2：核对规格 → 收三家 → 核对价格 → 批准 → 导出 → 归档；运费没核对

| 标准步骤 | 审计发现 | 影响 |
|---|---|---|
| 核对规格、收三家报价 | 记录显示已执行（“收三家”按上下文理解为三家报价） | 这两步未发现明确漏步 |
| 核对含税运费 | **明确遗漏运费核对**；“核对价格”未明确说明是否含税，税费核对待证实 | 总成本可能低估，供应商排序可能改变；审批所依据的成本可能不完整 |
| 经理批准 | 有“批准”记录且位于导出前，但未说明批准人是否为经理 | 审批顺序符合记录，审批权限仍需核实；不能直接认定经理批准已满足 |
| 导出、归档 | 均有记录且顺序正确 | 后续步骤完成，但不能抵消运费缺口及证据不足 |

**处理建议：**补核各家运费、税费口径及最终总成本，更新比较表；核实批准人身份。若影响原审批依据，应提交经理重新确认或批准，再同步导出文件和归档材料，并保留修订记录。

## 口头流程及越权下单

- “先收报价，然后问问采购规格”与标准顺序冲突：规格应在询价前核对，否则可能反复询价或比较不同规格。应按书面 SOP 统一执行。
- “经理批准才导出”与标准一致，但口头流程未完整覆盖三家报价、含税运费核对与归档，不能替代完整 SOP。
- “有人直接给供应商下单”是材料提及的额外问题，不得归因于 R1 或 R2。标准 SOP 未定义下单步骤，经理批准导出也不能自动解释为授权下单。应纠正直接下单行为，核查具体订单及授权，明确另行适用的采购下单审批流程。

## 审计结论

R1 的前置控制记录缺口较多，特别是导出前缺少经理批准证据；R2 明确漏核运费，另有含税口径和批准人身份的证据不足。两条记录均不足以认定完整符合标准 SOP。材料未提供金额、审批附件或实际订单，无法量化损失或断言已发生采购损失。
