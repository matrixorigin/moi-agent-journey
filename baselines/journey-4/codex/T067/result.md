# 采购流程中文 SOP

依据：直接读取 `samples/shared/flowchart.png`（标题 PROCUREMENT FLOW）。以下步骤忠实转写图中流程；图中没有规定的事项单独标注，不作为既定规则。

## 操作步骤

1. **核对规格**：检查采购对象的规格要求。图中未给出规格清单或判定标准。
2. **收集 3 份报价**：完成报价收集后进入比较环节。
3. **比较税费与运费**：对报价涉及的税费、运费进行比较。图中没有给出具体计算公式或选定供应商的规则。
4. **提交经理审批**：根据审批结果进入对应分支：
   - **批准**：导出并归档。图中未指定导出对象、文件格式和归档位置；完成该动作后，本图所示流程结束。
   - **拒绝**：修订报价。图中未明确修订后从哪个节点继续，不能据此认定已获批准或直接归档。

流程顺序：核对规格 → 收集 3 份报价 → 比较税费与运费 → 经理审批 → 批准后导出归档／拒绝后修订报价。
